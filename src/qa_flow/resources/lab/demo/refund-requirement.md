# 退款实验需求（合成数据）

> 本文为合成实验资料，不代表任何真实业务或真实公司规则。

## 1. 背景

运营人员需要对已支付订单发起部分或全额退款。金额单位为分。

## 2. 业务规则

- R1：退款金额必须为整数分，且 0 < 金额 ≤ 已支付金额 − 已退款金额；否则返回 400，账务不变。
- R2：只有退款操作员（refund_operator）可以提交退款；只读角色返回 403，且不产生任何副作用。
- R3：同一幂等键、同一请求内容重复提交时，返回同一笔退款；同一幂等键但内容不同时返回 409。
- R4：退款余额更新与退款记录必须原子提交；任一步失败时二者均不改变。
- R5：支付渠道的退款成功回调可能重复送达，同一回调只记账一次。
- R6：并发提交不同幂等键的退款时，总退款金额不得超过已支付金额。

## 3. 待确认

- 部分退款后，订单状态显示为“部分退款”还是保持“已支付”，文档未说明。
- 退款到账通知由哪个系统发送，产品尚未确定。
